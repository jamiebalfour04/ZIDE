<h1>ZIDE - ZPE Integrated Development Environment</h1>
<p>ZIDE, the official ZPE IDE, is the successor to ZPE's built-in text editor. ZIDE is designed to offer greater development support and a stunning JavaFX-powered UI, making it more flexible. </p>

<p>ZIDE is a lightweight, cross-platform integrated development environment built specifically to support the ZPE (ZPE Programming Environment) and the YASS programming language, while remaining flexible enough to work as a general-purpose code editor.</p>

<p>ZIDE is designed with a strong focus on clarity, speed, and control. Rather than attempting to replicate large, monolithic IDEs, it provides a carefully structured workspace that prioritises editing, running, and understanding code — especially in educational and experimental contexts.</p>

<h2>Key features</h2>
<h3>🧠 Native support for ZPE / YASS</h3>
<p>Tight integration with the ZPE runtime, including syntax highlighting, execution, and debugging workflows tailored to the language.</p>
<h3>🖥 Custom-built UI</h3>
<p>A bespoke interface (not a stock IDE skin), with custom window controls, theming, and layout — designed to feel modern without getting in the way.</p>
<h3>📂 Project-aware file browser</h3>
<p>Intelligent handling of file types, syntax modes, and editor behaviour based on file content and extension.</p>
<h3>⚙️ Process-based execution model</h3>
<p>Languages and tools run as external processes, providing isolation, flexibility, and better platform compatibility.</p>
<h3>🎓 Education-first philosophy</h3>
<p>Built by an educator, ZIDE is designed to support learning, experimentation, and understanding—not just production work.</p>

<h2>Planned features</h2>
<h3>🧩 Extensibility</h3>
<p>Support for external interpreters (such as Python and PHP) via installable extensions, keeping the core editor lean while allowing powerful expansion.</p>
