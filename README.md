ZIDE, the official ZPE IDE, is the successor to ZPE's built-in text editor. ZIDE is designed to offer greater development support and a stunning JavaFX-powered UI, making it more flexible. 

The functional basis of ZIDE is entirely grounded on the editor from ZPE itself. It will also include many features of the editor including the ZPE Macro Interface and the function machine. 

I am also hoping to make ZIDE into a multipurpose IDE that is not just limited to YASS.
